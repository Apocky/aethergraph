# Changelog

All notable changes to Aethergraph are documented here.

## 0.2.0 - 2026-08-02

Holistic memory-synthesis release.

- Adds an offline modulation organ that validates independent projection sources, deduplicates related lineages, preserves residuals, and allocates a bounded resting working set.
- Adds the `aethergraph.v4` renderer contract with controlled subjects, contexts, scoped importance and utility, activation, confidence, support, and visible degradation.
- Adds canonical explicit-key `aethergraph.ai.v1` JSONL for the agent-safe projection and a checksum-bound, reversible dictionary-coded companion for dense model ingestion.
- Makes active search spread through typed Primary, Context, and Archive relations while applying an adaptive deterministic working-set budget bounded by the declared resting limit.
- Keeps provider data outside the plugin and public repository; malformed, base-mismatched, degraded, inactive, private-target, and unknown-target sources contribute no provider signal and remain isolated as visible degraded or inactive receipts.
- Downgrades externally asserted verified evidence, allowlists semantic terms, limits provider-only edges to Context or Archive, and discounts older active sources through freshness scoring.
- Repairs the v3 schema fixture so its types match the real renderer contract.
- Raises the declared minimum Obsidian version to 1.13.4 and remains desktop-only.

## 0.1.0 - 2026-08-02

Initial public beta.

- Adds a focused graph view with Primary, Context, and Archive connection tiers.
- Explains each displayed connection with local evidence instead of treating missing shared tags as a domain boundary.
- Keeps diagnostics disabled by default and local when explicitly enabled.
- Applies a fail-closed diagnostic reference policy for unknown or withheld nodes.
- Ships a synthetic v3 fixture, schema, public-boundary checks, and release automation.

This beta is desktop-only while mobile behavior remains unverified.
